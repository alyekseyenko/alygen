## 💡 COMO USAR NO SIMULADOR

### **Estratégia de Preços:**

1. **Serviços Básicos (€20-25/h):**
   - Links sociais
   - ALT tags
   - Headers simples
   - Sitemap

2. **Serviços Médios (€30-35/h):**
   - SEO on-page
   - Tracking setup
   - CTAs
   - Copywriting

3. **Serviços Avançados (€40-45/h):**
   - Code splitting
   - Schema avançado
   - CSP
   - WhatsApp API

### **Fórmula do Simulador:**
```javascript
Preço Total = Σ (Horas × Preço/Hora específico do serviço)
```

**Exemplo:**
```
Performance:
- Otimização imagens (4h × €25) = €100
- Minificação código (3h × €30) = €90
- CDN setup (2h × €25) = €50
Total: €240

SEO:
- Meta tags (3h × €30) = €90
- Sitemap (2h × €25) = €50
- Schema (4h × €35) = €140
Total: €280

PREÇO FINAL: €520
```
