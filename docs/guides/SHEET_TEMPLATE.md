# Exemplo de Estrutura do Google Sheets

## Colunas Necessárias

Crie um Google Sheet com as seguintes colunas (exatamente com esses nomes):

| Nome | Email | Site | Status |
|------|-------|------|--------|
| Empresa ABC | contato@abc.com | https://abc.com | pending |
| Loja XYZ | vendas@xyz.com | https://xyz.com | pending |
| Consultoria 123 | info@123.com | https://123.com | pending |

## Colunas Opcionais (serão preenchidas automaticamente)

| Performance Score | Tem Pixel | Tem CTA |
|-------------------|-----------|---------|
| | | |

## Dados de Teste

Use estes sites reais para testar:

```
Nome: Amazon
Email: test@example.com
Site: https://www.amazon.com
Status: pending

Nome: Google
Email: test@example.com
Site: https://www.google.com
Status: pending

Nome: Site Lento (Teste)
Email: test@example.com
Site: https://www.webpagetest.org
Status: pending
```

## Após Análise

O sistema atualizará automaticamente as colunas:
- **Performance Score**: 0-100
- **Tem Pixel**: Sim/Não
- **Tem CTA**: Sim/Não
- **Status**: analyzed
