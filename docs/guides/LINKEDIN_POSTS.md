## **POST 3 - PERFORMANCE ENGINEERING**

**Título:** NumPy Vectorization: Como processei 1000+ leads em 1 segundo

O desafio de performance era real: analisar 1000+ websites simultaneamente sem rate limits ou timeouts. Loops tradicionais levariam minutos.

Solução: NumPy Vectorized Scoring com sector-aware weights.

Implementação:
- Sector-aware weights por negócio (ecommerce/b2b/saude/restaurante)
- NumPy dot product para cálculo extremamente eficiente
- Benchmarking competitivo local vs média da cidade
- Penalizações críticas: SSL ausente (-15pts), Performance <25 (-10pts)

Resultado: 100x mais rápido que loops tradicionais.

Mas a performance não é só speed - é resiliência:
- Swift Fetch (300ms) para sites standard
- Stealth Browser (2s) para Cloudflare/JS-heavy
- Google Oracle (5s) para fallback final

100% uptime garantido mesmo sob carga pesada.

Performance engineering é sobre otimizar cada milissegundo enquanto mantém resiliência total.

## **POST 6 - RESILIENCE ENGINEERING**

**Título:** 100% Uptime: Como construí sistema resiliente para produção

Produção é sobre sobreviver ao inesperado. Rate limits, APIs offline, timeouts - precisamos de fallbacks.

Sistema de Resiliência implementado:

Triple-Fallback Strategy:
1. Swift Fetch (Axios) - 300ms para sites standard
2. Stealth Browser (Puppeteer) - 2s para Cloudflare/JS-heavy
3. Google Oracle (PageSpeed API) - 5s fallback final

Groq Key Management:
- Múltiplas chaves API em pool
- Automatic failover em rate limits
- Health tracking por chave
- Reactivation automática após 5 minutos

Rate Limiting & Security:
- 200 requests/15min por IP (global)
- 10 análises/minuto (endpoints pesados)
- Worker isolation com retry-logic
- Winston structured logging

Immunity Shield System:
- Flag is_immune para clientes convertidos
- Auto-activation no Pipeline
- Visual feedback com escudo laranja
- Respeitado por todos os workers

100% uptime não é sorte - é engenharia deliberada.
